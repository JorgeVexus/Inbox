## Para quien reciba preguntas técnicas del cliente

Dos comandos con **exactamente los mismos headers** (importante: sin headers de
navegador, hasta `curl` recibe el reto, y eso confunde la comparación). El primero
pasa; el segundo recibe el reto de Cloudflare:

```bash
UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"

# curl -> 200
curl -s -o /dev/null -w "%{http_code}
" -X POST https://apitest.inbox.com.mx/Login   -H "Content-Type: application/json" -H "User-Agent: $UA"   -H "Origin: https://apitest.inbox.com.mx" -H "Referer: https://apitest.inbox.com.mx/" -d "{}"

# Node (lo que usa el sitio) -> 403 challenge
node -e "fetch('https://apitest.inbox.com.mx/Login',{method:'POST',headers:{'Content-Type':'application/json','User-Agent':'$UA',Origin:'https://apitest.inbox.com.mx',Referer:'https://apitest.inbox.com.mx/'},body:'{}'}).then(r=>console.log(r.status,r.headers.get('cf-mitigated')))"
```

Causa: Cloudflare distingue por la huella TLS del cliente HTTP, no solo por los
headers; no se resuelve desde el código de la aplicación. Verificado 2026-10-12
desde la IP 187.189.155.14.
